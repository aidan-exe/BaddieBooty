# Baddie Booty proposal concept

A Next.js App Router concept site by **Aidan Lottering** for Baddie Booty (owner Tiara). It is **not** the live store at [baddiebooty.co.za](https://baddiebooty.co.za/).

Routes: `/` `/shop` `/shop/[slug]` `/cart` `/checkout` `/about` `/contact`

Product photos and logo are Baddie Booty brand assets sourced from the live store for this client proposal only.

The demo bag and checkout do not process payment. A WooCommerce rebuild that adds live payments and SA shipping is a paid engagement.

```bash
npm install
npm run dev
npm run build
```
